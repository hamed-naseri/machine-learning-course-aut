
# Machine Learning with Python

This repository contains the course materials for **Machine Learning with Python**.

The course is taught in Persian and focuses on hands-on learning using Python and popular machine learning libraries.

## Course Topics

1. Python Fundamentals and Machine Learning Workflow
2. Linear Regression and Correlation
3. Multicollinearity and Feature Selection
4. Regression Methods
5. Classification
6. Model Selection and Hyperparameter Tuning
7. Explainable Machine Learning
8. Clustering

## Tools and Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- SHAP

## How to Use the Notebooks

Each session is provided as a Jupyter Notebook and can be opened directly in Google Colab.

Students can run and modify the code in Colab without changing the original files in this repository.

To save your own version:

**File → Save a copy in Drive**
